# MTS 용출 분석 — GitHub Pages 배포 패키지

이 패키지는 앞서 제공한 용출 분석 v2의 암호화 배포 페이지에 GitHub Pages 자동 배포 설정을 추가한 정적 웹앱입니다. npm 설치나 별도 백엔드는 필요하지 않습니다. 이번 패키징에서는 분석 코드를 변경하지 않았습니다.

## 포함 파일

- `index.html`은 비밀번호로 암호화한 앱 실행 페이지입니다.
- `.nojekyll`은 정적 파일 제공을 위한 파일입니다.
- `.github/workflows/deploy-pages.yml`은 Pages 자동 배포 설정입니다.
- `.gitignore`는 로컬 산출물과 실험 자료의 실수 커밋을 줄이는 설정입니다.
- `README.md`는 이 배포 및 사용 안내입니다.

## 기존 MTS-dissolution 저장소에 적용합니다

1. 기존 저장소 파일을 백업합니다.
2. 이 ZIP의 압축을 풉니다. ZIP 자체가 아니라 압축 안의 파일과 폴더를 저장소 최상위에 올립니다. `index.html`이 하위 폴더에 들어가지 않게 합니다.
3. `.github/workflows/deploy-pages.yml`도 반드시 반영합니다. 숨김 파일이 보이지 않는 환경에서는 GitHub의 Add file → Create new file에서 해당 경로를 입력하고 YAML 내용을 붙여넣어 생성합니다.
4. 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 설정합니다. 기존에 다른 Pages 배포 워크플로가 있으면 중복 배포되지 않도록 정리합니다.
5. `main` 또는 `master` 브랜치에 커밋하면 배포가 실행됩니다. 설정 전에 커밋했다면 Actions → Deploy MTS dissolution to GitHub Pages → Run workflow를 실행합니다. 다른 브랜치를 사용하는 저장소에서는 YAML의 branches를 실제 브랜치명으로 수정합니다.
6. Actions의 deploy 작업 성공 여부와 작업이 표시하는 URL을 확인합니다. 기존 저장소와 Pages 주소 설정을 유지했다면 주소는 `https://leesmts.github.io/MTS-dissolution/`입니다.
7. 브라우저를 강력 새로고침한 뒤 기존에 알려주신 비밀번호로 잠금을 해제합니다. 실제 시험자료를 넣기 전 대표 데이터로 입력·계산·저장·그래프 표시를 확인합니다.

GitHub 웹 업로드는 숨김 파일을 누락할 수 있습니다. 업로드 후 저장소에서 `.github/workflows/deploy-pages.yml`의 존재를 확인합니다. GitHub Desktop이나 git을 사용하면 폴더 구조를 보존하기 편리합니다. .gitignore는 이미 추적 중인 파일이나 웹 UI로 직접 올린 파일을 막는 보안 장치가 아니므로 실제 시험자료를 올리지 않습니다.

### 기존 브랜치 방식으로 간단히 배포하는 경우

자동 배포 설정을 사용하지 않으려면 `index.html`과 `.nojekyll`만 기존 Pages 배포 위치에 교체하고 기존 Deploy from a branch 설정을 유지할 수도 있습니다. 이때 이 패키지의 워크플로는 추가하지 않습니다. 두 배포 방식을 중복으로 구성하지 않습니다.

## 앱 사용 방법

대조약과 시험약의 전용 칸에 각각 Excel 표를 붙여넣습니다. 시간 머리글과 제제 번호를 포함해 복사하는 것이 좋습니다. 병합 셀에서 생긴 빈 사이 열은 자동 처리하며 실제 누락값은 결측으로 남깁니다. 적용 전에 인식된 시간·제제 수·값을 확인합니다. 하나의 붙여넣기 칸에는 한 군의 표만 넣습니다.

원자료를 적용하면 평균·표본 SD·CV를 계산하며 그래프의 색상, 마커, 레이블, 밴드 등을 설정할 수 있습니다. f₂ 계산 시 선택된 시점과 적용 조건 경고를 확인합니다. CV 기준을 초과하면 부트스트랩을 선택할 수 있습니다. 부트스트랩은 각 군의 제제별 전체 시간 프로파일을 복원추출하고 percentile 90% 신뢰구간을 계산합니다. 신뢰구간 하한 50 충족 여부는 보조 분석 정보이며 규제상 동등성을 자동 확정하지 않습니다. 결측값이나 개별 원자료 부족은 먼저 해결해야 합니다.

원자료와 설정은 JSON으로 별도 백업할 수 있으며 CSV/PNG 저장을 지원합니다. 브라우저 저장 기능은 암호화된 연구 데이터 저장소가 아닙니다. 공용 PC에서는 데이터를 남기지 않도록 주의합니다.

## 비밀번호 및 데이터 보안

기존에 알려주신 비밀번호가 적용된 암호화 `index.html`을 그대로 포함했습니다. 비밀번호 자체와 잠금 없는 검토용 HTML, 실제 시험 엑셀은 포함하지 않았습니다. 서버 계정 인증이나 사용자별 권한 관리 기능은 없습니다. 잠금 해제한 사용자는 복호화된 앱을 열람·복사할 수 있습니다. 규제 데이터 보관이나 조직 접근 통제 시스템을 대체하지 않습니다.

암호화된 파일이므로 HTML 문자열을 직접 바꾸는 방법으로 앱 내부 기능이나 비밀번호를 수정할 수 없습니다. 기능 수정은 별도로 보관한 검토용 소스를 수정한 후 다시 암호화해야 합니다. 잠금 없는 소스와 비밀번호를 공개 저장소에 올리지 않습니다.

Chart.js와 데이터 레이블 플러그인을 CDN에서 읽으므로 인터넷 연결이 필요합니다. 이 패키지는 설치형 PWA 또는 완전 오프라인 앱이 아닌 브라우저용 정적 웹앱입니다.

## 확인한 범위와 미완료 사항

이번 작업에서는 배포 ZIP의 파일 구성과 원래 배포용 index.html과의 바이트 일치를 확인했습니다. GitHub 저장소 변경, GitHub Actions 실제 실행, 공개 사이트 반영 및 실제 브라우저 검수는 수행하지 않았습니다. 분석 알고리즘은 앞서 제공한 v2와 동일하며 이번 패키징에서 새로 검증하지 않았습니다. 업무 적용과 규제 제출 전에는 적용 프로토콜에 맞는 검증이 필요합니다.

## 제작 근거

이 패키지의 앱은 앞서 제공한 `MTS-dissolution_v2_배포용.zip`의 `index.html`을 그대로 사용합니다. 앱 원본은 사용자 제공 `용출률_그래프_생성기.html`을 기반으로 확장한 버전입니다.
