# 용출률 그래프 · 유사성(f2) 분석 앱

브라우저만 있으면 되는 **완전 정적(static) 웹앱**입니다. 서버·DB가 필요 없어
**GitHub Pages**에 그대로 올리면 "링크 + 비밀번호"로 누구나 사용할 수 있습니다.

## 구성 파일
| 파일 | 설명 |
|------|------|
| `index.html` | 앱 본체 (그래프 + f2 + 부트스트랩, 엑셀 읽기 포함) |
| `config.js`  | 로그인 비밀번호(해시)·앱 제목 설정 |
| `README.md`  | 이 안내서 |

> Chart.js, chartjs-plugin-datalabels, SheetJS(xlsx)는 CDN에서 자동으로 불러옵니다.
> (별도 설치 불필요, 인터넷 연결만 있으면 됩니다.)

---

## 1) GitHub에 올리기 (GitHub Pages 배포)

1. GitHub에서 새 저장소(repository) 생성 — 예: `dissolution-app`  (Public 또는 Private 모두 가능)
2. `index.html`, `config.js`, `README.md` 세 파일을 저장소에 업로드(Add file → Upload files → Commit)
3. 저장소 **Settings → Pages** 로 이동
4. **Source** 를 `Deploy from a branch`, **Branch** 를 `main` / `/ (root)` 로 지정하고 Save
5. 1~2분 뒤 상단에 표시되는 주소(`https://<사용자명>.github.io/dissolution-app/`)가 **접속 링크**입니다.
6. 이 링크를 공유하면, 받은 사람은 링크 접속 → 비밀번호 입력 → 바로 사용합니다.

## 2) 로그인(비밀번호) 설정

- **기본 비밀번호: `dissolution2026`**
- 비밀번호는 `config.js` 의 `PASSWORD_HASH`(SHA-256 해시)로 저장됩니다. 평문은 저장하지 않습니다.
- 바꾸는 법: 브라우저 F12 → Console 에서 아래 한 줄 실행 후, 나온 64자리 해시를 `config.js` 에 붙여넣기

```js
(async p => Array.from(new Uint8Array(
  await crypto.subtle.digest('SHA-256', new TextEncoder().encode(p))
)).map(b=>b.toString(16).padStart(2,'0')).join(''))('새비밀번호')
```

- 로그인하면 기본 12시간 동안 세션이 유지됩니다(`config.js` 의 `SESSION_HOURS` 로 조정).

### 보안 수준에 대한 솔직한 안내
이 방식은 "아는 사람끼리 공유용 간단 잠금"입니다. 정적 사이트라 비밀번호 해시가
브라우저 소스에 포함되므로 **기밀 데이터용 강력한 인증은 아닙니다.** 더 강한 보호가 필요하면:
- **Cloudflare Access** (무료 플랜, 이메일 OTP) 를 GitHub Pages 앞단에 연결, 또는
- **Netlify / Vercel 의 Identity / Password Protection** 기능 사용, 또는
- 사내망 전용 호스팅
을 권장합니다. (앱 코드는 그대로 두고 호스팅만 바꾸면 됩니다.)

## 3) 사용 방법

### 0. 엑셀 불러오기 (선택)
식약처 KiFDA "비교용출 종합표(.xlsx)" 를 올리면 `기시용출액` 시트 맨 아래 요약표
(`용출시간` 행 → 시험약/대조약의 mean·CV)와 12 vessel 개별 보정 용출률을 자동으로 읽어
그래프 시리즈와 f2 입력칸, 부트스트랩 개별값을 채웁니다.
자동 인식이 안 되면 아래 칸에 직접 입력하면 됩니다.

### 1~2. 그래프
- 채취시간(분)을 쉼표로 입력 → 시리즈별 색/마커/값 입력 → **그래프 그리기**
- '기준'으로 지정한 시리즈 ± 밴드 폭으로 상·하한 밴드가 그려집니다.
- **PNG로 저장** 으로 이미지 내려받기.

### 3. 유사성(f2)
- 시점별 **대조약 평균 / CV / 시험약 평균 / CV** 입력 → **f2 계산**
- f2 = 50·log₁₀{ [1 + (1/n)·Σ(R−T)²]^(−1/2) · 100 }, **f2 ≥ 50 이면 유사**
- **CV 조건 자동 점검**: 첫 사용시점 CV ≤ 20%, 이후 시점 CV ≤ 10%
  - 충족 → 기본 f2 사용 가능
  - 초과 → "부트스트랩 권장" 안내가 뜹니다.

### 4. 부트스트랩 f2 (90% 신뢰구간)
- 반복 횟수 입력 → **부트스트랩 실행**
- 시점별로 **둘 다 85% 미만 / 하나만 85% 이상 / 둘 다 85% 이상** 을 분류해 보여줍니다.
  ('85% 규칙 자동선택' 버튼으로 사용 시점도 자동 지정 가능)
- 방법:
  - **비모수**: 개별 12 vessel 값을 재표본(권장). 개별값 칸이 채워져 있으면 자동 선택.
  - **모수**: 개별값이 없으면 mean·CV(→SD)로 정규분포에서 생성.
- 결과: f2 분포의 **90% 신뢰구간(5~95 백분위)**. **하한 ≥ 50 이면 유사.**
