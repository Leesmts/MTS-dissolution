3. 유사성(f2) 계산

대조약(R) · 시험약(T)의 시점별 평균 / CV(%) 입력

4. 부트스트랩 f2 (90% 신뢰구간)

대조약(R) 개별값 (선택) · 행=vessel, 열=시점(쉼표)

시험약(T) 개별값 (선택)

개별값이 있으면 비모수 재표본(권장), 없으면 mean·CV로부터 정규분포 모수 부트스트랩을 수행합니다. 열 순서는 아래 f2표의 '사용' 체크된 시점 순서와 같아야 합니다.
계산식: f2 = 50·log₁₀{ [1 + (1/n)·Σ(R−T)²]^(−1/2) · 100 } · 판정: f2 ≥ 50 이면 유사 · 부트스트랩 판정: 90% CI 하한 ≥ 50 이면 유사
